# Source-driven development

Identify the authoritative source and exact version. Separate requirements
stated by the source from local interpretation and verify unstable technical
facts against primary documentation.

Map source concepts to local interfaces without copying unnecessary structure.
Record ambiguous or intentionally divergent behavior and the reason for it.

Build conformance examples or tests for the relevant requirements. Respect
licenses and quotation limits; link or cite sources instead of embedding large
copied passages.
