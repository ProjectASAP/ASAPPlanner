# ASAPPlanner documentation

Choose the path that matches what you need to do.

## New to ASAPPlanner

1. Read the [planner pipeline](concepts/planner-pipeline.md).
2. Use the [glossary](concepts/glossary.md) when a term is unfamiliar.
3. Learn the roles of the [Pre-ASAP IR](concepts/pre-asap-ir.md) and [Post-ASAP IR](concepts/post-asap-ir.md).
4. Run one query with [the inspection guide](guides/run-a-query.md).

## Run or inspect a query

Follow [Run and inspect a query](guides/run-a-query.md). Tool-specific setup stays with the tool, including the [DAG viewer instructions](../tools/dag-viewer/RUNNING.md).

## Extend the planner

1. Read the [ASAP-aware mapping architecture](architecture/asap-aware-mapping-implementation.md).
2. Consult [mapping contracts](reference/asap-aware-mapping-contracts.md).
3. Follow [Extend ASAP-aware mapping](guides/extend-asap-aware-mapping.md).

## Understand a design

- [Architecture](architecture/README.md) describes stable system boundaries and flows.
- [Decisions](decisions/README.md) records accepted local choices.
- [Proposals](proposals/README.md) records evolving designs and research directions.
- [Reference](reference/README.md) specifies current interfaces, IR nodes, formats, and evidence.
