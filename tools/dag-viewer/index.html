How to read it
  • Big box (a group): one intermediate result, e.g. "the p50 of the last 10 minutes".
  • Small boxes inside (candidates): different ways to compute that same result. Border colour shows which rule added it.
  • Arrow: the candidate reads its input from the group it points to.
  • Green: the selected plan uses it. Red dashed: pruned (shown only with "show pruned candidates").
  • Small grid (Pass 2 tab): how Stage 2 can run the candidate. Rows: computed at ingest or at query time. Columns: result not kept, kept for one query run, kept across runs. Filled = possible, crossed = ruled out, dark outline = used by the plan.
